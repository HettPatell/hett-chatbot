# Hett — Minimalist Text-Only Chatbot

Hett is a pure, distraction-free conversational web application. It enforces a strict zero-emoji design philosophy across all interfaces, buttons, prompts, and artificial intelligence responses.

---

## Key Features

- Pure Text Design: Zero emojis, zero icons, and zero decorative symbols.
- High-Legibility Typography: Clean system sans-serif with an optional monospace terminal mode.
- Dark and Light Themes: Optimized for low-light environments and daytime readability.
- Zero Dependencies: Built strictly with HTML5, CSS3, and JavaScript. No build step or Node.js required.
- Built-in Text Engine: Ready to use immediately without an API key or internet connection.
- Optional Live Model Integration: Built-in support for Google Gemini and OpenAI with strict anti-emoji system prompts.

---

## Local Usage

1. Navigate to the project directory:
   ```text
   C:\Users\ADMIN\.gemini\antigravity\scratch\hett-chatbot
   ```
2. Double-click `index.html` to open Hett directly in any web browser.

---

## Deployment to Vercel (Free)

1. Create a repository on GitHub (leave "Add a README file" unchecked).
2. Upload the files in this directory (`index.html`, `style.css`, `app.js`, `vercel.json`, `README.md`).
3. On Vercel (vercel.com), select "Add New Project" and import your GitHub repository.
4. Click "Deploy". The site will be live immediately.

---

## Deployment to Netlify Drop (Alternative)

1. Open `https://app.netlify.com/drop` in your web browser.
2. Drag and drop the `hett-chatbot` directory directly onto the browser window.
3. Your deployment will receive an HTTPS URL in seconds.
